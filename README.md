# GYM-PLAN · QB 核心强化训练卡

一个**单文件、离线可用**的健身房训练卡 Web App：按训练日浏览动作、四种分期参数同屏、点一下打勾、内置休息计时器。为「四分卫核心与全身力量」16 周计划定制，但结构通用，改数据即可换成任何计划。

## 直接用

- **线上**：`https://jiakaihu47.github.io/GYM-PLAN/`（iPhone Safari 打开 → 分享 → 添加到主屏幕）
- **离线**：把 `index.html` 存进手机「文件」App 打开即可。iOS 文件预览会禁用 JavaScript，因此本页做成**静态优先**：内容与打勾照常可用，只有计时器不出现——用系统计时器代替。

## 文件

| 路径 | 作用 |
|---|---|
| `index.html` | 训练卡本体（GitHub Pages 根路径必须叫这个名字） |
| `sw.js` | Service Worker 离线缓存：https 打开一次后，健身房没信号也能用 |
| `.nojekyll` | 关掉 Jekyll 处理，避免静态文件被吞 |
| `plan/QB-16周训练计划.pdf` | 完整计划书 23 页（三顾问 + 决策会议 + 安全闸门 + 每日详表 + 核心库 + 营养 + 测试） |
| `plan/QB-16周训练计划.md` | 同一份内容的纯文本版，可搜索可编辑 |
| `plan/手机速查卡.txt` | 手机速查版，适合粘进「备忘录」 |
| `plan/训练记录表.xlsx` | 训练日志 / 主项进度 / 测试电池 / 周检视 4 张表，带成长曲线公式 |
| `src/data.mjs` | **训练计划数据层**：分期、训练日、动作、组次、节奏、要点全在这里 |
| `src/gen-*.mjs` | 渲染器：分别生成 PDF 用 HTML、训练卡、Markdown、部署包 |

## 设计取舍（为什么写得这么"笨"）

iOS「文件」App 预览网页时会禁用 JavaScript。很多单页工具因此一打开就是白屏，所以这里：

- **所有内容预渲染进静态 HTML**，不依赖脚本生成
- **打勾用原生 `<input type="checkbox">`**（点整行即可），不需要一行 JS
- **四种分期参数同时列出**，不靠按钮切换
- **导航用锚点 + 原生滚动**
- JavaScript 只做增强（计时器 / 进度条 / 记住打勾 / 高亮当前日），脚本不可用时这些元素自动隐藏，不会出现空壳

## 改计划 / 重新生成

```bash
node src/gen-card.mjs    # → 训练卡 HTML
node src/gen-print.mjs   # → 打印用 HTML（再用 Chrome --print-to-pdf 转 PDF）
node src/gen-md.mjs      # → Markdown 计划书
node src/deploy.mjs      # → 部署包（index.html + sw.js）
```

改动作、组次、分期只需要动 `src/data.mjs`，四个输出会一起更新。

更新线上页面时，**把 `sw.js` 里的 `CACHE` 版本号改掉**（`qb-card-v2` → `v3`），否则手机上会一直看到旧缓存。

# GYM-PLAN · QB 训练卡

一个**单文件、离线可用**的健身房训练卡 Web App：按训练日浏览动作、四种分期参数同屏、点一下打勾、内置休息计时器。为「四分卫核心与全身力量」16 周计划定制，但结构通用，改数据即可换成任何计划。

## 直接用

- 线上：`https://jiakaihu47.github.io/GYM-PLAN/`（在 iPhone Safari 打开 → 分享 → 添加到主屏幕）
- 离线：把 `index.html` 存进手机「文件」App 打开即可（iOS 的文件预览会禁用 JavaScript：**内容与打勾照常可用**，只有计时器不出现——用系统计时器代替）

## 设计取舍（为什么写得这么"笨"）

iOS「文件」App 预览网页时会禁用 JavaScript。很多单页工具因此一打开就是白屏，所以这里：

- **所有内容预渲染进静态 HTML**，不依赖脚本生成
- **打勾用原生 `<input type="checkbox">`**（点整行即可），不需要一行 JS
- **四种分期参数同时列出**，不靠按钮切换
- **导航用锚点 + 原生滚动**
- JavaScript 只做增强（计时器 / 进度条 / 记住打勾 / 高亮当前日），脚本不可用时这些元素自动隐藏，不会出现空壳

## 离线缓存

`sw.js` 是 Service Worker：首次用 https 打开后会把整页缓存到本地，之后健身房没信号也能打开。

更新页面时记得把 `sw.js` 里的 `CACHE` 版本号改掉（`qb-card-v2` → `v3`），否则手机上会一直看到旧缓存。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 训练卡本体（GitHub Pages 根路径必须叫这个名字） |
| `sw.js` | 离线缓存 |
| `.nojekyll` | 关掉 Jekyll 处理，避免静态文件被吞 |
